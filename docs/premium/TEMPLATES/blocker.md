# 阻塞记录模板

blocker_id: Bxx
opened_at: 真实时间
task_ids: []
status: OPEN / RESOLVED
category: RESOURCE / AUTHORIZATION / ENVIRONMENT / DESIGN_CONFLICT
observed_fact: 实际失败及证据引用
missing_input: 具体资源、权限或信息；不写秘密
unblock_condition: 可验证的解锁标准
owner: 谁能提供
independent_work: 仍可继续的任务ID
next_command: 解锁后第一条命令
resolved_at/evidence: 解决后填写
