# ADR-001 — Premium v1 scope, authority boundary, and frozen interfaces

- Status: accepted for T03
- Date: 2026-10-17
- Supersedes: the V0-only limits named in SPEC.md; it does not supersede the five product roles, DSH-only, real-research evidence, PostgreSQL authority, or Master-only DAG mutation.

## Context

RAVEL's existing V0/Phase10/Phase11 implementation is the scientific core. The premium handoff (docs/premium/SPEC.md) adds a Desktop-first client, cloud-resident reliability, HPC targets, human-lab handover, a single mailbox, evidence reports, Docker-first sandboxing, and an operator-provisioned SSH VM provider. The handoff is the binding scope; this ADR records how the new interfaces attach to the existing core without creating a second project/DAG/evidence system.

## Decisions

1. **RAVEL is the only scientific core.** The Electron/React client is a thin consumer of the Gateway. It does not own project state, DAG state, evidence, approvals, or leases.
2. **DSH remains the only harness.** The existing pin and the per-`(project, role)` process isolation stay. This round does not merge to one Host, switch harness, or add a multi-harness adapter.
3. **The five product roles do not change.** Master / Research / Review / Compute Worker / Experimental Worker. Deterministic scheduling, routing, leasing, and notification are software components, not new Agents.
4. **Master remains the only DAG/contract mutation authority.** The desktop user can set goals, approve Actions, pause/resume, and set the authority envelope; the user cannot edit the DAG. Research, Review, Workers, and the development Supervisor cannot mutate the DAG.
5. **PostgreSQL is authoritative; Temporal is durable execution only.** DSH session context is never project state. Artifact bytes live in S3-compatible storage; PostgreSQL stores immutable references, hashes, and metadata.
6. **Execution, Review, and Decision remain separate.** Workers execute a frozen contract, Review independently accepts/diagnoses, Master decides. Simulated computation is labelled `SIMULATED`; it cannot become `COMPUTATION` or `HUMAN_LAB` evidence.
7. **Real research stays real.** Web/paper/database research must open the source before registering evidence; paywalls and inaccessible sources stay `PAYWALLED/AUTH_REQUIRED/ACCESS_LIMITED`. Unit tests may use fixtures; live acceptance may not.
8. **Human-lab events are person-reported.** An authorized operator signs/acknowledges; software cannot impersonate the operator or confirm that an instrument stopped. The system withdraws a handover; it does not generate `STOP_CONFIRMED`.
9. **Mail is one dedicated IMAP TLS + SMTP TLS account.** Outbound mail needs an Owner approval bound to the exact payload; SMTP uncertainty becomes `UNKNOWN_DELIVERY`, never an automatic resend. Mail bodies are untrusted content, not Owner instructions.
10. **Sandbox providers are Docker first, then an operator-provisioned SSH VM.** Agents hold no Docker socket, cluster, or cloud credential. A missing capability returns `UNSUPPORTED`; it never silently degrades to the host.
11. **The first compute science route is RASPA adsorption/GCMC.** The calculation manifest carries the frozen scientific parameters, software/environment digest, inputs/hashes, resource request, required outputs, and stop conditions.
12. **Internal and external completion are separate.** T23 is at most `INTERNAL_READY_EXTERNAL_PENDING/BLOCKED`; full certification requires real CVM/COS, HPC, human lab, mailbox, and VM evidence (T24–T29).
13. **The contract schemas are the integration surface.** `schemas/premium/**` defines Lease, Action, Approval, BudgetReservation, Mailbox, MailMessage, SandboxHandle, ProjectEvent, HpcTarget, CalculationManifest, HumanLabEvent, and ScientificReport. Existing domain names may be reused, but each new field maps to a schema field and a persistent column/constraint.
14. **Identity is never model-supplied.** Tool calls resolve `project_id`, `role`, `binding_id`, `owner_instance_id`, and `lease_epoch` from the trusted runtime binding/Gateway principal. A stale binding cannot be upgraded to a new epoch; a takeover revokes it.
15. **The development Supervisor/Reviewer/Subagent are not product roles.** They are engineering organization only.

## Consequences

- New migrations add lease/action/budget/mail/sandbox/event tables and indexes; they extend, rather than replace, the existing project/DAG/evidence tables.
- The Gateway gains `/v1` while preserving existing TUI routes.
- The Desktop client consumes snapshots plus the ordered event stream; it never receives harness credentials.
- External rows stay explicitly blocked; no mock or simulation is promoted to real evidence.
