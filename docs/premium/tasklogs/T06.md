## 安全 Review 修复

背景 security review 对 070406f 报出 4 个问题，932f7e2 修复：
- approval 记录必须是同一 Action kind；`_verify_approval` 拒绝 record mismatch。
- unknown cost 在正额度下也不能按 0 预留；必须有显式正 upper bound。
- `record_accepted/complete/record_unknown/record_failed_confirmed/reconcile` 必须有 reporter，默认取数据库中的 claimant；非 claimant 必须是 live Owner。
- `_verify_contract_unchanged` 对所有 contract-bound Action（不只 COMPUTE_SUBMIT）检查 contract 版本。
- `cancel` 仅允许 Action 的请求者或 live OWNER/ADMIN，普通 member 不能释放预算/关闭他人的 Action（7b98f6f）。
- 新增 `test_outcome_reports_require_the_claimant_or_a_live_owner` 及 unknown-cost 正额度回归。
- 迁移约束名改用 `op.f(...)`，修复 fresh DB 上 naming convention 双前缀导致的 schema gate 失败（4fa6ee3）。
