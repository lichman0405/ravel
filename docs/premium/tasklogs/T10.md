## 实现

1. `src/ravel/compute/raspa/route.py`：唯一路线
   `raspa/gcmc-gas-adsorption`，方法固定 `GCMC`，RASPA 版本系列固定 `2.0`；DFT、MD、
   NVT/NPT、Gibbs、CFCMC、conductivity、pore size distribution 等明确列入
   `UNSUPPORTED_METHODS`。`SUPPORT_MATRIX` 记录 `real_run_task=T25`、
   `real_run_status=BLOCKED_EXTERNAL`、具体 blocker/unlock 与
   `evidence_scope=implementation and deterministic verification only`。
2. `src/ravel/compute/raspa/provenance.py`：官方 RASPA2 仓库固定到 tag `v2.0.47`、
   commit `673ad2d52a9c11e5ee7db9e5e7339663bfabecf9`；六条 `SourceRecord`（COPYING、
   官方 `simulation.input`、MFI_SI 结构、ExampleZeolitesForceField 力场、
   pseudo atoms、methane 分子定义）各有真实 path、raw URL、MIT license、引用与
   SHA-256。`read_bundled` 按内容校验，不按文件名相信。
3. `src/ravel/compute/raspa/contract.py`：`RaspaScientificContract` 从冻结的
   `ExecutionContract` 读取 17 个必需科学项（method、温度/单位、压力/单位、cycles、
   initialization cycles、print every、unit cells、三种 MC 概率、seed、framework、
   molecule、molecule definition、force field）。缺项/空值
   `MISSING_SCIENTIFIC_PARAMETER`；非 RASPA software 或非 GCMC
   `UNSUPPORTED_ENVIRONMENT`；单位、数值、路径式名称
   `INCONSISTENT_CONTRACT`。温度与压力规范化为 K/Pa；`bar` 仅在数值明确时换算，
   不允许隐式假设。模型记忆中缺失的科学值从不补齐。
4. `src/ravel/compute/raspa/package.py`：确定性、不可变输入包。只打包一个官方可再
   分发参考系统（MFI_SI + methane + ExampleZeolitesForceField + ExampleDefinitions）；
   调用方输入必须与固定 digest 逐字节一致，否则拒绝。manifest 不含时间、主机路径或
   object key；相同 contract/acceptance 两次构建的 manifest 与
   `package_sha256` 逐字节相同，contract version 或任一科学项/标准变化必然产生新包。
   manifest 在运行前固定 `required_outputs`、输出文件名、parser schema id/version/
   digest、三种结果状态、两种 evidence class、收敛策略（5 blocks、相对标准误差
   <= 0.05、数值相对容差 1e-6，明确标注为 RAVEL 自选 provisional threshold）、
   frozen Review criteria 及其 digest。`verify_input_package` 重读并验证 digest、
   字节数和 strict 模式下的额外文件。
5. `src/ravel/compute/raspa/environment.py`：启动前探测二进制、版本、license 与
   bundled data。`ProbeRefusal` 闭集：`SOFTWARE_MISSING`、`PROBE_FAILED`、
   `VERSION_MISMATCH`、`LICENSE_UNAVAILABLE`、`DATA_MISSING`、`DATA_MISMATCH`、
   `BINARY_DIGEST_MISMATCH`。每个拒绝都带 `return_to=MASTER` 与结构化 document；
   license 必须是 MIT 文本；data digest 必须匹配 pin；可用
   `expected_binary_sha256` 固定二进制身份。
6. `src/ravel/compute/raspa/parser.py`：解析真实 RASPA 2.0 输出。只有
   `SourceKind.REAL_RUN` 产生 `COMPUTATION`；`REFERENCE_FIXTURE` 与
   `TEST_FIXTURE` 一律 `SIMULATED` 且附 `evidence_reason`。状态机顺序明确：
   UTF-8、版本系列、状态点、完成行、warnings、loading 统计、block 编号、单位换算
   先判 `SOFTWARE_FAILURE`；block 数不足或相对标准误差超阈值判
   `NON_CONVERGED`；否则 `NORMAL`。非零 exit code 即使文本正常也是软件失败。
   输出值、单位、seed、cycles 与解析所依据的 checks 都写入 canonical result
   document 并可重算 SHA-256。
7. `src/ravel/compute/raspa/ledger.py`：`trace_result` 是只读的逐项追踪器，任何不一致
   以闭集 `TraceRefusal` 拒绝并返回 Master。它验证 manifest digest、result 与 package/
   frozen scientific contract/execution contract 的一致性；要求 project-scoped
   Ledger 中存在 execution 行且 `output_refs` 命名该 artifact；要求四个输入 artifact
   versions 的 content hash 与 size 匹配且非 simulated；要求六条 `EvidenceSource`
   按官方 URL/hash 可读；校验单位；要求 acceptance contract 已冻结、绑定到该 node、
   criteria digest 等于包内记录，且 `frozen_at <= result artifact created_at`。
   fixture 登记为 computation、criteria 事后修改、输入/来源缺失、执行缺失、结果
   hash 不符、包被编辑等分别被具名拒绝。
8. Schema：`schemas/premium/compute/raspa_scientific_contract.schema.json`、
   `raspa_input_package.schema.json`、`raspa_result.schema.json`，均为 draft
   2020-12、`additionalProperties=false`，与代码中的 manifest/result 文档逐项对应；
   parser schema 的 SHA-256 固定进每个包。
9. 测试：`tests/premium/T10/`，140 cases，全部使用真实 PostgreSQL 行（AC3）与
   真实文件系统；唯一替身是 object store（`MemoryStore` 实现 `ArtifactStore` 协议），
   已在模块 docstring 说明。fixture 在 `fixtures/FIXTURES.json` 明确标注：
   官方 RASPA 输出为 `REFERENCE_FIXTURE`/`SIMULATED`，内存合成输出为
   `TEST_FIXTURE`/`SIMULATED`，两者都不会被登记为真实结果。
