## 实现

1. `src/ravel/domain/enums.py`：新增 `ReportDataMode`（REAL/SIMULATED/MIXED）、
   `EvidenceExecutionType`（RESEARCH_SOURCE/COMPUTATION/HUMAN_LAB/SIMULATED）、
   `ReportStatus`（CERTIFIED/REPORT_CONFLICT）、`ReportConflictCode`
   （FABRICATED_SOURCE/FABRICATED_EXECUTION/HASH_MISMATCH/MISSING_LOCATOR/
   MISSING_EXECUTION_REF/WRONG_EXECUTION_COUNT/SIMULATED_AS_FACT）。
2. `src/ravel/reports/models.py`：不可变 pydantic 记录与请求类型。
   - `ReportRequest` 只有 title/claims/evidence/limitations；`EvidenceRequest` 只有
     evidence_id/locator/content_hash；`ClaimRequest` 只有 statement/claim_type/
     evidence_ids/execution_refs/execution_node_id/execution_count。**没有**
     `data_mode`/`execution_type` 字段，作者无法自带类型标签。
   - `ScientificReport` 校验 CERTIFIED 必须无 conflict、REPORT_CONFLICT 必须有 conflict；
     `ReportSnapshot.report_json()` 只输出冻结 schema 的六个键；
     `certified_json()` 对冲突报告抛 `ReportNotCertified`。
   - `ReportCommentary` 只允许 MASTER 角色；`ReportSnapshot` 中 commentary 是独立记录。
3. `src/ravel/reports/classification.py`：仅从 provenance 推导类型，项目作用域读取
   evidence/source/artifact/version/execution/backend job/review/deviation。
   - fixture 来源（`fixture:` provenance、`fixture://` URL）、`SIMULATED_KIND`、
     `simulated_provenance(...)`、`mock-*` backend/job 一律 SIMULATED；
   - `lab-upload:*`/`human-lab` → HUMAN_LAB；`slurm:*`/真实执行 → COMPUTATION；
   - evidence 继承其 source 的最强类型；无法读取/未知来源保持 RESEARCH_SOURCE；
   - `original_record` 保存推导所依据的原始行，重命名/改标签不能改变类型。
4. `src/ravel/reports/builder.py`：确定性、不修复的装配器。
   - 索引真实 ledger 行并渲染 executions（total/real/simulated/by_status/by_backend）、
     backend_jobs、artifacts 与版本、reviews（含冻结准则 ref/version）、deviations、
     evidence_index（类型/locator/ledger hash/原始行）、conflict_codes、ledger_digest。
   - 校验：evidence 必须存在；断言 hash 必须等于 ledger hash；research source 必须有
     page range/locator；computation claim 必须带 execution refs；count/node 必须与
     ledger 一致；FACT 不得建立在 SIMULATED 证据上。
   - 失败不静默修正、不静默丢弃：写入 REPORT_CONFLICT 及 asserted/actual/original_record；
     失败 claim 不落库；冲突报告可读但不可 certified export。
   - rendered 不含每份报告随机的 claim_id，两个快照同一 ledger 的 rendered 完全相等。
5. 持久化：
   - `src/ravel/state/tables.py` 新增 `scientific_reports`、`report_claims`、
