## 设计决定

- **限流键与代理信任**：键是 `(client_ip, normalized username)`。只有当 TCP peer 在
  `RAVEL_GATEWAY_TRUSTED_PROXIES` 中时才采用 `X-Forwarded-For` 的最右非受信地址；
  否则忽略该头，避免客户端自选限流桶。锁按滑动窗口实现，状态保存在进程内并设有
  上限，V0 单 CVM 单 Gateway 的部署假设与 `SECURITY_NOTES` 一致。
- **账号停用**：`users` 保持 append-only（guards 的默认行为），停用写成一条新的审计行。
  没有新增 Gateway 管理路由；实现保留为 repository 动作，供运维/后续 T22 接线。
- **上传流式**：`S3ArtifactStore` 位于 `state/store.py`（不在 T07 白名单），因此不修改它；
  在 `gateway/routes/artifacts.py` 内部定义 `StreamingS3ArtifactStore`，用
  `tempfile.SpooledTemporaryFile` 接收路由的块、边写边哈希，再以文件对象作为
  `put_object` 的 Body。内存上界是 spool 阈值，不随文件线性增长。
- **浏览器 fail-closed**：在 `BrowserNavigator.open/links` 的最前面检查 provider，
  失败发生在 Playwright 导入与线程提交之前。T19 绑定沙箱后只需新增合法 provider
  标识；空值与未知值一律拒绝。
