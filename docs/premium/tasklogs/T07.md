## 实现

1. `src/ravel/gateway/auth/policy.py`（新）：
   - `validate_gateway_settings` 在 `create_app` 打开数据库之前无条件运行；生产环境拒绝 shipped
     JWT secret、开发 PostgreSQL 密码/DSN、空或开发 S3 secret；要求 loopback/私网 bind、
     HTTPS `public_origin`、非空且全为精确 HTTPS Origin 的 allowlist、非空 trusted proxies。
   - `parse_origins`/`exact_origins` 把 Origin 规范化为主机小写、去默认端口、保留 IPv6 方括号；
     wildcard、带路径/凭据/查询的条目拒绝；未配置的 allowlist 是空集而不是全集。
2. `src/ravel/gateway/auth/limits.py`（新）：`LoginRateLimiter` 以 `(client_ip, casefold(username))`
   为键，滑动窗口实现 5/60s 与 20/900s，锁 900s；`retry_after` 在密码校验之前运行；
   仅当 peer 在 trusted proxies 中时采用 `X-Forwarded-For`，且从右向左取第一个非受信地址；
   异常链回退到 peer；状态为进程内 LRU（上限 10,000 组合），与单 CVM 单 Gateway 的 V0 假设一致。
3. `src/ravel/gateway/routes/auth.py`：登录接上限流器，锁定返回 429 + `Retry-After`，
   失败路径对未知账号与错误密码给出同一语句，成功登录清除该组合的失败历史。
4. `src/ravel/gateway/routes/events.py`：握手先校验精确 Origin，再在数据库线程中认证；
   连接存续期间每 `gateway_stream_reauthorize_seconds`（默认 4.0，上限 5.0）重新执行
   `authenticate` + `standing_in`；关闭码 4401/4403/4404/1011；watcher 在 `finally`
   取消并等待，且内部异常不会被误报为撤权。
5. `src/ravel/state/tables.py` + 迁移 `20261019_1200_7e4c1b2a9d3f_account_deactivations.py`
   + `src/ravel/state/repositories/identity.py`：新增 append-only `account_deactivations`；
   `UserRepository.by_username/get` 叠加停用事实；`deactivate` 校验命名的操作者、先确认账号
   存在、重复停用幂等；`users` 行保持原样，由数据库 guard 拒绝改写与删除。
6. `src/ravel/gateway/routes/artifacts.py`：`request.stream()` 分块读入
   `NamedTemporaryFile(delete=False)`，边读边计数；声明 `Content-Length` 超限时在读取 body
   之前返回 413；所有路径 `finally` 关闭并 unlink 临时文件。新增 `StreamingS3ArtifactStore`：
   块写入 `SpooledTemporaryFile(max_size=1 MiB)` 并同步哈希，再以文件对象为 `Body`、
   `IfNoneMatch="*"` 上传；412/409/precondition 映射为 `ArtifactImmutableError`，其他失败只
   记录异常类型；对外 502/503 使用固定语句。

## 配置与部署

生产环境（`RAVEL_ENV=production`）启动前必须具备：

| 配置 | 要求 |
|---|---|
| `RAVEL_GATEWAY_JWT_SECRET` | 真实密钥，≥32 字节；不得等于 shipped 值 |
| `RAVEL_POSTGRES_PASSWORD` / `RAVEL_POSTGRES_DSN` | 不得使用 `ravel_dev_password` |
| `RAVEL_S3_SECRET_KEY` | 非空且不得等于开发默认值 |
| `RAVEL_GATEWAY_HOST` | loopback 或私网地址；公网 bind 必须显式 `RAVEL_GATEWAY_ALLOW_PUBLIC_BIND=true` |
| `RAVEL_GATEWAY_PUBLIC_ORIGIN` | `https://` 裸 origin，且必须出现在 allowlist 中 |
| `RAVEL_GATEWAY_ALLOWED_ORIGINS` | 逗号分隔的精确 HTTPS Origin；WebSocket 逐请求精确匹配 |
| `RAVEL_GATEWAY_TRUSTED_PROXIES` | 非空 CIDR 列表（反向代理地址）；只有这些 peer 的 XFF 被采信 |
| `RAVEL_GATEWAY_UPLOAD_LIMIT_BYTES` | 正整数，默认 67108864（64 MiB/文件） |
| `RAVEL_GATEWAY_STREAM_REAUTHORIZE_SECONDS` | `0 < x <= 5`，默认 4.0 |
| `RAVEL_RESEARCH_BROWSER_SANDBOX_PROVIDER` | T19 之前保持未设置；空值/未知值一律拒绝浏览器抓取 |

部署形态：HTTPS 由反向代理终止并转发到私网/loopback 上的 Gateway；代理必须覆盖而不是
追加客户端提供的 `X-Forwarded-For`。V0 为单 CVM 单 Gateway，限流状态不跨进程共享。
